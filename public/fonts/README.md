# Fonts

The game self-hosts two fonts (latin subsets, WOFF2) from Google Fonts. The font files live in
`src/ui/fonts/` so Vite can fingerprint them; their licences live here so they ship with the build.

| Font    | Used for                     | Licence                                       |
| ------- | ---------------------------- | --------------------------------------------- |
| Bangers | Titles, word pops, buttons   | SIL Open Font License 1.1 (`OFL-Bangers.txt`) |
| Fredoka | Interface text, ball numbers | SIL Open Font License 1.1 (`OFL-Fredoka.txt`) |
